## 📌 Featured Projects

### 🔐 Cryptographic Permutations
- **[Krakken-2048 Abyssal](https://github.com/effjy/krakken)** – 2048‑bit SPN‑ARX hybrid permutation with MDS branch number 9.
- **[Krakken-2048 Butterfly](https://github.com/effjy/krakken-butterfly)** – Enhanced version with XOR‑Rotation Butterfly Diffusion (XRBD), reducing rounds from 10 to 8.

### 💾 Post‑Quantum Encryption
- **[Krakken-Disk](https://github.com/effjy/krakken-disk)** – Linux encrypted volume manager using Kyber‑1024/X448 + AVX2 permutations.
- **[Krakken-Disk Butterfly](https://github.com/effjy/krakken-disk-butterfly)** – Faster variant using the Butterfly permutation.

### 🛡️ Systems Security
- **[KageAlloc](https://github.com/effjy/kagealloc)** – MPK‑based memory allocator with temporal safety, 3.8% overhead over ptmalloc.
- **[TIDS](https://github.com/effjy/tids)** – Topological Intrusion Detection using persistent homology (0.03% FPR on CIC‑IDS2017).

### 🧹 Forensic Sanitization
- **[Virtual Wipe Turbo](https://github.com/effjy/vwipe)** – Multi‑threaded GUI secure erasure suite (NIST SP 800‑88).
- **[Secure Wipe](https://github.com/effjy/swipe)** – Command‑line counterpart for files, free space, and RAM.

### 📊 Monitoring & Tools
- **[Usage](https://github.com/effjy/usage)** – GTK3 real‑time network traffic monitor with Tokyo Night theme.
- **[Secure Mount](https://github.com/effjy/secure_mount)** – GTK3 frontend for gocryptfs.
