<h2 id="background">📖 Background & Expertise</h2>

Over **20+ years** bridging operational security, network administration, and cryptographic design—a rare intersection of practical security operations and theoretical cryptanalysis.

For more than a decade, I've independently researched and engineered symmetric permutations with a philosophy: **every component serves a cryptanalytic purpose**. Every S‑box, rotation, and linear layer neutralizes vulnerabilities that others might miss.

The **Krakken project** embodies this philosophy—a family of wide‑state, SPN‑ARX hybrid permutations designed for post‑quantum resilience and provable security properties.

**Current Focus:**
- Designing cryptographically secure, post‑quantum symmetric primitives
- Developing high‑assurance security tools for forensics and encryption
- Building hardware‑accelerated cryptographic systems with zero security compromise
- Advancing automated cryptanalysis using constraint solvers and formal methods
